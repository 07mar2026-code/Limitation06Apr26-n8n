## 五、狀態用語

- `PASS`：已有本輪可回讀的執行證據。
- `PASS／未發布`：測試通過，但只存在未發布副本或獨立測試鏈。
- `FAIL`：執行結果不符合條件；保留作歷史證據。
- `未確認`：舊證據可能過期，或缺少當前精確回讀。
- `未執行`：尚未實際執行案例。

未發布副本、本機模組或合成測試通過，不等於 M2.2 正式歷史記憶、屬靈文章模組或正式 LINE Bot 已上線。
